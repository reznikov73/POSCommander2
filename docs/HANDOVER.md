## Ловушки (проверено на практике)

- **exe занят** — линковка падает с `cannot open output file`: закрывать процесс
  строго по имени `POS Commander`. Не убивать по маске `POS*`: под неё попадают
  `poscloud-client` и `poscloud-server`, их уже случайно останавливали.
- **ini перезаписывается при выходе**. Для чистого теста удалять и новый
  `POS Commander.ini`, и старый `POSCommander2.ini` (иначе миграция подтянет старый
  и приложение откроет прежние вкладки).
- `GetWindowText` из другого процесса для EDIT возвращает пустую строку — читать
  через `WM_GETTEXT`/скриншот.
- `PostMessage` в ListView не двигает курсор: навигация — реальными кликами и
  `keybd_event`; Ctrl-комбинации проверять через `WM_COMMAND`.
- Скрипты с кириллицей запускать `pwsh -File`, а не через `powershell.exe`.
- CMake: `.ico` добавлены в `OBJECT_DEPENDS`, иначе `ninja` не пересобирает `.rc`
  после перерисовки иконок (внешне: exe не меняется).
- `%TEMP%` в pwsh может быть пустым — брать `[System.IO.Path]::GetTempPath()`.
