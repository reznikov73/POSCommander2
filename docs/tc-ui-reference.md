# Интерфейс Total Commander: что видно на эталонных скриншотах

Записано 08.11.2026 по 8 скриншотам TCUP 9.0a (русский интерфейс), чтобы детали не потерялись.

## Главное окно

- Заголовок окна: «Total Commander 9.0a - PowerUser v68», сеть 0,0 Мбит/с, память 14,7/15,9 ГБ (92 %),
  ЦП 5–35 %, кнопка «ТС РУ», «Выход».
- Меню: Файл, Выделение, Навигация, Сеть, Вид, Вкладки, Конфигурация, Инструменты, Запуск, Помощь.
- Тулбар: ~15 кнопок с иконками (архив, просмотр, правка, копия, перенос, каталог, удаление,
  мультипереименование, поиск, синхронизация, сравнение, FTP и т. п.), сепараторы, поле быстрого фильтра.
- Панель дисков: буквы `C: D: E:` + `\` + `..` + «[рабочий] 1 253,4 ГБ из 3 726,0 ГБ свободно».
- Две вкладки на панель, у активной — подсветка; путь в редактируемом поле с выпадающей историей;
  справа поле маски `*.*` с выпадающим списком.
- Колонки: Имя, Тип, Размер, Дата (+ Атр), сортировка по клику со стрелкой.
- Строка статуса панели: `e:\Work\GIGA\GigaDev>` — путь под курсором; снизу F-клавиши
  «F3 Просмотр, F4 Правка, F5 Копирование, F6 Перемещение, F7 Каталог, F8 Удаление, Alt+F4 Выход».

## История каталогов (выпадающий список из поля пути)

Список последних каталогов с галочкой у текущего, например: `E:\Work\GIGA\GigaDev\`, `E:\Work\GIGA`,
`E:\Work`, `E:\`, `E:\Distr\`, `E:\Games\`, `E:\Work\VSC\POSCommander2\build\` и т. д.

## Иконки

- папка — классическая жёлтая с язычком; у скрытых папок поверх левого края красная полоса;
- `..` — чёрная стрелка вверх;
- файлы — значки ассоциаций, у exe/lnk своя иконка (у ярлыка — со стрелкой).
