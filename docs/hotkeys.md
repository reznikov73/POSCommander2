## Чего ещё нет (по убыванию пользы)

1. **F1 — справка** (нужен контент: README + эта таблица).
2. **Ctrl+Shift+F5 — создать ярлыки**, **Ctrl+Num+/− — выделить всё/снять всё**,
   **Alt+Num+/− — выделить по расширению файла под курсором**, **Num / — вернуть прежнее выделение**.
3. **Ctrl+Shift+B** — ветка только для выделенных файлов и папок.
4. **Ctrl+P** — добавить текущий путь в командную строку; **Shift+Enter** — запуск через `cmd /k`.
5. **Ctrl+Shift+U** — сменить панели вместе со всеми вкладками; **Ctrl+Shift+W** — закрыть
   все неактивные вкладки (сейчас закрываются все).
6. **Shift+Tab** — переход между панелью и деревом каталогов.
7. Просмотрщик: `Alt+Enter` (есть), `F11`, `Ctrl+Shift+C` (hex-копия), `Ctrl+P` (печать),
   `F`/`L`/`C` для изображений — у нас нет просмотра картинок.

## Служебные клавиши наших диалогов

- Поиск (`Alt+F7`): `Enter` — начать/выбрать, `Esc` — закрыть, `Tab` — по полям.
- Синхронизация, дубликаты, сравнение, переименование — клавиши внутри диалогов стандартные.
