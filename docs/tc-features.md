# Сравнение с Total Commander: разбор отчёта внешнего агента

Дата сверки: 08.11.2026. Отчёт был сделан **без запуска приложения** (по README, план.txt и чтению исходников),
поэтому часть выводов — гипотезы. Ниже проверка каждого пункта по коду и работе программы.

## Что в отчёте верно

| Замечание | Состояние у нас | Комментарий |
|---|---|---|
| Кнопки дисков/вкладки/тулбар/F-клавиши — стандартные `BUTTON` | так и есть: `panel.cpp` (диски, вкладки), `main.cpp` (тулбар, F-клавиши, `BS_FLAT`) | в TC кнопки плоские, с иконками, вкладки рисуются сами |
| Заголовок пути — `STATIC` | так и есть (`panel.cpp`, `header_`) | в TC путь кликабельный: клик по части пути — переход, двойной — ввод |
| Ширины колонок не сохраняются | верно, в INI только окно, разделитель, вкладки, сортировка | |
| Нет стрелок сортировки в заголовке | верно: `LVS_NOSORTHEADER`, сортировка по `LVN_COLUMNCLICK` есть, стрелки не рисуются | |
| В строке состояния нет информации о файле под курсором | верно: только «Файлов/Папок/Отмечено/свободно» | |
| На панели дисков только буквы | верно: без иконок типов, без `\` и `..`, без меток томов | |
| Диалог F5/F6 без маски и флажков «перезаписать/в фоне» | верно: только путь | |
| Вкладки без блокировки, дублирования и своего меню | верно: есть добавить/закрыть/переключить/клик | |
| Подписи F-клавиш не меняются по Shift/Ctrl/Alt | верно: статичные | |
| Нет настройки шрифта, цветов и тёмной темы | верно | |
| Нет `Num + / − / *`, `Ctrl+PgUp/PgDn`, `Ctrl+Q`, `Ctrl+P`, `Shift+F4`, `F9`, `Alt+←/→` | верно | |

## Что в отчёте неверно (проверено по коду и запуском)

| Утверждение агента | Фактически |
|---|---|
| «Не видел `NM_CUSTOMDRAW`, возможно цветов нет» | есть: `panel.cpp`, `CDDS_ITEMPREPAINT` → `DrawRow`; отмеченные красит `RGB(200,0,0)` (как в TC), скрытые — серым |
| «`Ctrl+U` не реализован» | реализован: `case 'U'` → `IDM_SWAP` |
| «`Alt+Shift+Enter` (размеры каталогов) отсутствует» | реализован: `IDM_DIRSIZE`, счёт в фоновом потоке |
| «`Shift+F6` не реализован» | реализован: `if (shift && msg.wParam == VK_F6) → IDM_RENAME` |
| «`Ctrl+F3…F6` (режимы колонок) отсутствуют» | реализованы: сортировка по имени/типу/размеру/дате в блоке `if (ctrl)` |
| «Имя и расширение — одна колонка» | у нас четыре колонки: Имя (stem), Тип (ext), Размер, Дата |
| «`Ctrl+↑/↓` — истории командной строки нет» | история есть: `CB_ADDSTRING` в `RunCommandLine`, но навигация стрелками не привязана |

Дополнительно у нас уже есть то, что в отчёте не упомянуто как существующее: поиск `Alt+F7` с фоном,
просмотр `F3` с кодировками и hex, архивы как папки (`7z.exe`), очередь операций, пакетное переименование
`Ctrl+M`, закладки `Ctrl+D`, дерево `Ctrl+F8`, контекстное меню Проводника, перетаскивание (внутри и из
Проводника), размеры каталогов, настройки в INI, `--selftest` (29 проверок).

## Ошибки про сам TC

- Панель дисков в TC по умолчанию показывает **буквы**, иконки — опция; «нужны иконки» — вкусовое, не факт.
- «Имя и расширение отдельными колонками» — у нас уже так.
- В TC ПКМ по файлу по умолчанию **не отмечает** файл, а открывает контекстное меню (поведение настраивается).

## Что имеет смысл делать (мой порядок)

1. **Кликабельный путь** в заголовке: клик по компоненту пути → переход, двойной клик → поле ввода.
2. **Информация о файле под курсором** в строке состояния (имя, размер, дата, атрибуты).
3. **`Num + / − / *`** — отметить/снять/инвертировать по маске.
4. **`Ctrl+PgUp` / `Ctrl+PgDn`**, `Ctrl+\` — наверх, войти, корень.
5. **Ширины колонок в INI** + выравнивание размера вправо + «<DIR>» для каталогов + стрелки сортировки.
6. **Owner-draw вкладок и кнопок** (плоский вид, «×» на вкладке, закрытие средней кнопкой).
7. **Диалог F5/F6** с маской и флажками «перезаписать», «в фоне».
8. **Контекстное меню вкладок** с блокировкой и дублированием.
9. Мелочи: `Alt+←/→`, подписи F-клавиш по модификаторам, `Shift+F4`, `F9`, `Ctrl+Q`.

Отдельно: шрифт и цвета в INI, тёмная тема — это уже «полировка», делать после пунктов 1–6.
