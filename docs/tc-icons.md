# Иконки в стиле Total Commander

Иконки панели рисует `tools/make_icons.py` (Pillow), результат — `.ico` в `res/`:

| Файл | Ресурс | Что это |
|---|---|---|
| `res/folder.ico` | 102 | жёлтая папка |
| `res/folder_hidden.ico` | 103 | скрытая папка: светлее + красный пунктир |
| `res/arrow_up.ico` | 104 | строка «..» — серая стрелка вверх с загибом вправо |
| `res/app.ico` | 101 | иконка приложения — дискета (оранжевый корпус, синяя шторка, белая наклейка) |

Размеры внутри каждого `.ico`: 16/20/24/32/48 (приложение — 16…256, крупные записи в PNG).
Каждая иконка рисуется в 8× и уменьшается LANCZOS, поэтому на 16 px нет грязи.

## Как сняты данные

Геометрия и цвета взяты попиксельно с вырезок из TC (16 px) и повторены в векторном виде.
Исходные вырезки: `tools/ref_folders.png` (папки), вырезка стрелки — в истории задачи.

Папка — координаты уже в пикселях 16-пиксельной сетки:

- корпус: строки 2…12, столбцы 0…14; углы скошены на 1 px (справа сверху и снизу,
  слева снизу);
- язычок: строки 0…1, верх x 2…6, основание x 1…7; нижняя кромка язычка не обводится —
  её перекрывает корпус;
- контур: сверху `#A46D05`, слева `#B97A00`, справа `#875B0C`, снизу `#8E5F0A`;
- заливка: `#FFF8C5` → `#FDDE84`; справа внутри фаска `#F0C771` → `#C89F54`,
  над нижней кромкой полоса `#C79F55` (проявляется слева направо).

Скрытая папка — та же форма светлее: язычок `#F8F1C6`, корпус `#F9F5DC → #F8E8BB`,
контур `#D6B679` / справа `#BDA77F` / снизу `#BDA77F`, фаска `#F7E3B9 → #DDC9A3`,
полоса `#DDC9A4`. Метка: белая полоса 2 px (столбцы 7…8) от верхней кромки до полосы
над низом, красный пунктир `#C43D47` двумя штрихами (строки 3…6 и 9…10),
с белой окантовкой 1 px (столбцы 6…9 на штрихах).

Стрелка: наконечник (6.6, 1.2), правое плечо (12.1, 6.1), ступенька до x 9.0,
ствол вниз до y 10.1, «ступня» до x 13.1, низ y 14.0, левое плечо (1.0, 7.0);
заливка `#D6D6D6 → #888888`, контур `#3E3E3E`.

## Точность

Скрипт сравнивает наши 16 px с вырезкой: среднее расхождение по каналам —
папка 6.4/255, скрытая папка 3.7/255 (фон исключён). Остаток — сглаживание
краёв в эталоне и двухцветный пунктир.

## Иконка приложения (дискета)

Доли сняты с эталона 2048×2048 построчным разбором:

| Элемент | Границы |
|---|---|
| корпус | x 0.124…0.881, y 0.078…0.890, закругление 0.075 |
| верхний правый угол | срезан по диагонали от (0.760, 0.072) к (0.886, 0.198) |
| шторка | x 0.265…0.699, y 0.078…0.388; слева тёмная полоса до x 0.320, справа блок от x 0.560 |
| окно шторки | x 0.509…0.631, y 0.139…0.360 (оранжевое, тело дискеты) |
| створка | x 0.551…0.631, y 0.161…0.354 |
| наклейка | x 0.251…0.753, y 0.478…0.891 (до нижней кромки) |
| полоски | x 0.307…0.699, высота 0.022, шаг 0.069 |

Цвета: корпус `#FC7C16`, шторка `#16294E` (тёмные края `#0D1E3D` и `#0C1C38`),
створка `#0A1731`, наклейка `#F1F3F5`, полоски `#11274B`.

Для 16…24 px рисуется отдельная целая сетка 16 (корпус 2…14, шторка 4…11,
наклейка 4…12, 2–3 полоски) — иначе детали сливаются. Для 24 px и выше —
4 полоски, для 32 px и выше — плюс окно и створка шторки.

## Перерисовка

```
python tools/make_icons.py            # перерисовать .ico в res/
python tools/make_icons.py --compare  # сравнение с вырезкой: tools/compare.png
python tools/make_icons.py --preview  # общий лист: tools/preview.png
```

`.ico` добавлены в `OBJECT_DEPENDS` в CMakeLists, поэтому `ninja` пересобирает `.rc`
после перерисовки иконок.
