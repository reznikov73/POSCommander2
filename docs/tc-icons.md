# Иконки в стиле Total Commander

Иконки панели рисует `tools/make_icons.py` (Pillow), результат — `.ico` в `res/`:

| Файл | Ресурс | Что это |
|---|---|---|
| `res/folder.ico` | 102 | жёлтая папка |
| `res/folder_hidden.ico` | 103 | скрытая папка: светлее + красный пунктир |
| `res/arrow_up.ico` | 104 | строка «..» — серая стрелка вверх с загибом вправо |
| `res/app.ico` | 101 | иконка приложения |

Размеры внутри каждого `.ico`: 16/20/24/32/48 (приложение — 16…256, крупные записи в PNG).
Каждая иконка рисуется в 8× и уменьшается LANCZOS, поэтому на 16 px нет грязи.

## Как сняты данные

Геометрия и цвета взяты попиксельно с вырезок из TC (16 px) и повторены в векторном виде.
Исходные вырезки: `tools/ref_folders.png` (папки), вырезка стрелки — в истории задачи.

Папка (координаты в пикселях вырезки 23×35 → сетка 16×16 по `fx(x)=x-3.5`,
`fy(y)=(y-4)*0.93+2.5`):

- корпус: x 4…18, y 6…16;
- язычок: трапеция x 4…11, y 4…6.4, левый скос круче правого;
- контур корпуса разными оттенками: сверху `#A46D05`, слева `#B97A00`,
  справа `#875B0C`, снизу `#8E5F0A`;
- заливка: вертикальный градиент `#FFF8C5` → `#FDDE84`, блик сверху `#FFFFFF` (55 α),
  тень по низу `#D7BA6D`.

Скрытая папка — та же геометрия, цвета светлее: язычок `#F8F2C8`, корпус
`#F9F5DC → #F8E8BB`, контур `#D6B679` / справа `#BDA77F` / снизу `#C0A97E`,
тень `#E5D6B0`; белая полоса x 9.6…13.6 и красный пунктир `#BE3842`
двумя штрихами (y 7.0…10.4 и 12.0…14.4).

Стрелка: наконечник (6.6, 1.2), правое плечо (12.1, 6.1), ступенька до x 9.0,
ствол вниз до y 10.1, «ступня» до x 13.1, низ y 14.0, левое плечо (1.0, 7.0);
заливка `#D6D6D6 → #888888`, контур `#3E3E3E`.

## Перерисовка

```
python tools/make_icons.py            # перерисовать .ico в res/
python tools/make_icons.py --compare  # сравнение с вырезкой: tools/compare.png
python tools/make_icons.py --preview  # общий лист: tools/preview.png
```

`.ico` добавлены в `OBJECT_DEPENDS` в CMakeLists, поэтому `ninja` пересобирает `.rc`
после перерисовки иконок.
