# Наши диалоги и элементы интерфейса (факты по скриншотам)

Записано 09.11.2026, чтобы детали не зависели от файлов-снимков.

## Диалог «Отметить по маске» (Num + / - / *)

Заголовок: «Отметить по маске» (для Num- — «Снять отметку по маске», для Num* — «Инвертировать по маске»).
Строка: «Маска (несколько — через запятую):». Поле заранее заполнено `*.*`. Кнопки: OK (по умолчанию), Отмена.

## Диалог копирования/перемещения (F5/F6)

Заголовок «Копирование» или «Перемещение». Строка вида «Копировать «обычная папка» в:» (для одного файла —
имя в кавычках, для нескольких — «Копировать файлов: N в:»). Поле пути с автодополнением, ниже
«Маска файлов:» (пустая = все), два флажка: «Перезаписывать без запроса», «В фоне (в очередь операций)».
Кнопки OK / Отмена. Размер диалога 330×128 единиц.

## Контекстное меню вкладки

Пункты: «Открыть копию этой вкладки», «Открыть копию на другой панели», «Переименовать вкладку…»,
разделитель, «Заблокировать вкладку» (у заблокированной — «Разблокировать вкладку»), разделитель,
«Закрыть вкладку», «Закрыть все вкладки». Последние два неактивны, если вкладка одна.

## Вкладки

Активная вкладка светлая с рамкой по трём сторонам, неактивная серая. У каждой «×» (закрытие),
у заблокированной — замок слева от подписи. Минимальная ширина 70 px, максимальная 230 px,
ширина = текст + 40 px (плюс 13 px под замок).

## Заголовок списка

Колонки: «Имя» (имя без расширения), «Тип» (расширение), «Размер» (по правому краю), «Дата».
Маркер сортировки — треугольник «▲/▼» прямо в тексте заголовка выбранной колонки.

Причина, почему маркер делается текстом: `HDF_SORTUP`/`HDF_SORTDOWN` через `Header_SetItem` на нашем
ListView не отрисовывались (проверено снимком заголовка), а стиль `LVS_NOSORTHEADER` вообще отключал
клики по заголовку — сортировка мышью не работала до 09.11.2026.

## Раскладка окна (ориентир)

Окно 1180×760, клиентская часть 1164×701. Панель 580 px: ряд дисков + объём одной строкой (24 px),
вкладки (24), поле пути с кнопками (24), список, строка состояния (22). Тулбар 30 px, ряд F-клавиш 30 px,
командная строка 26 px.
