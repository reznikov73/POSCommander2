# PosFiles

Двухпанельный файловый менеджер в духе Total Commander. Чистый Win32 API, C++20, без внешних зависимостей.
Продукт — **PosFiles**; репозиторий исторически называется `POSCommander2`.

Цель — скорость и сходство с TC: запуск до окна ~60–120 мс, память ~15 МБ, exe ~2,6 МБ.

## Сборка

Нужны CMake 3.20+, Ninja и компилятор.

```powershell
cmake --preset mingw-release
cmake --build --preset mingw-release
```

Пресет `mingw-release` сам добавляет `C:\Tools\w64devkit\bin` в `PATH`; отдельно прописывать
компилятор не нужно.

Готовый файл: `build\PosFiles.exe`. Проверено на MinGW-w64 GCC 16.1 (`C:\Tools\w64devkit`); MSVC поддерживается в CMake, но на этой машине не проверялся (пресет `msvc-release`).

## Запуск и проверка

```powershell
.\build\PosFiles.exe              # обычный запуск
.\build\PosFiles.exe --selftest   # самопроверка, код возврата = число провалов
.\build\PosFiles.exe --ftp-test 127.0.0.1:2121:test:test   # сквозная проверка FTP
```

Отчёт самопроверки: `%TEMP%\posfiles-selftest.txt`, отчёт FTP-проверки: `%TEMP%\posfiles-ftp-test.txt`.
Для локальной проверки FTP есть `tools/ftp_test_server.py` (Python 3, без зависимостей):

```powershell
python tools\ftp_test_server.py --port 2121 --user test --password test --root <каталог>
```

## Настройки

Файл `PosFiles.ini` рядом с exe (пишется при выходе, до закрытия окна). При первом запуске
он автоматически переносится (переименовывается) из старого `POS Commander.ini` или
`POSCommander2.ini`, если те лежат рядом; после успешной миграции старые файлы удаляются.
В нём: положение и размер окна,
развёрнутость, пропорция разделителя, скрытые файлы, сортировка, ширины колонок (Имя/Тип/Размер/Дата),
вкладки обеих панелей — пути, подписи, блокировки, активная вкладка, активная панель, позиция курсора
и маска в каждой панели, история масок (последние 8), сохранённые FTP-профили. После перезапуска
восстанавливается то же окно, те же вкладки, курсоры и маски.

Пароли FTP-профилей пишутся в INI в обфусцированном виде (обратимая маскировка, **не** шифрование).

Удалить файл — вернуться к значениям по умолчанию.

`Num+/−` — масштаб, `Alt+Enter` — полный экран, `1/2/3/4` — кодировки, `H`/`T` — hex/текст.
## Заголовок окна

Как в TC, в заголовке одна строка состояния, обновляется раз в секунду:

```
PosFiles - Win32   Пн 09 ноя 2026 01:07:33   Сеть: 13,9/6,9 Мбит/с   Память: 10,1/15,9 ГБ (63%)   ЦП: 18%
```

- дата и время — локальные, день недели и месяц сокращённо по-русски;
- сеть — принято/передано за последнюю секунду по самому нагруженному интерфейсу
  (виртуальные адаптеры дублируют трафик, поэтому не сумма);
- память — занято/всего и процент загрузки (`GlobalMemoryStatusEx`);
- ЦП — загрузка за интервал между обновлениями (`GetSystemTimes`).

## Поле пути и строка состояния

Путь над списком показывает текущий каталог и **не редактируется**. В этом состоянии он работает как
«хлебные крошки»: клик по компоненту пути (`E:`, `posc2-perf`, `icons`) переходит в этот каталог.

Клик по **свободному месту** справа от текста (или двойной клик по полю) включает режим правки:
белый фон, мигающий курсор в точке клика и появляется кнопка **✓**. Дальше:

- `Enter` или кнопка **✓** — перейти в этот каталог; поле снова становится нередактируемым, **✓ исчезает**;
- `Esc` — отменить правку и вернуть прежний путь;
- клик мимо поля (по списку) — тоже выход из правки с восстановлением пути.

Пока поле в режиме правки, `Backspace`, `Delete`, `Space` и буквы работают как обычный ввод и не дергают
панель (раньше `Backspace` уводил на уровень вверх).

Справа от поля — **поле маски** `*.*`, затем кнопки пути:

- **✓** — перейти по введённому пути;
- **★** — избранные каталоги (закладки) и пункт «Добавить текущий каталог»;
- **▼** — история посещённых каталогов (последние 24, свежие сверху), она же по `F4` или `Alt+↓`.

**Поле маски** (между путём и кнопками): клик включает правку, `Enter` (или `Tab`) применяет маску
и перечитывает список, `Esc` отменяет. Маска действует только на файлы — каталоги и «..» остаются
всегда, как в TC; `*.*`, `*` или пусто — показать всё, включая файлы без расширения. Можно несколько
масок через `;` или запятую: `*.cpp;*.h`. Кнопка **▼** рядом с полем открывает историю последних
8 масок (общая для обеих панелей) с пунктом «*.* — все файлы».

Строка состояния под списком: слева — полный путь записи под курсором (при нехватке места сокращается
слева: `…\src\main.cpp`), справа — «Отмечено: N · размер», когда есть отметки.

При наведении мыши на запись списка показывается подсказка с полным путём — у каталогов с завершающей
обратной чертой (`E:\posc2-perf\icons\`, как в TC). Такая же подсказка есть у поля пути.

Если навести мышь на **компонент пути** (`E:`, `Work`, `VSC`, …), через ~0,35 с под ним открывается
выпадающий список содержимого этого каталога — как в TC: папки и файлы с иконками, вертикальная полоса
прокрутки. Список «живой»: в него можно перевести мышь, он не закроется; строку можно выделить кликом,
колесо мыши прокручивает список, двойной клик по папке переходит в неё. Закрывается, когда мышь уходит
и с пути, и со списка, а также при входе в режим правки пути.

## Колонки

Как в TC: у каталогов колонка «Тип» **пустая**, а в «Размере» стоит `<Папка>`; после расчёта размера
(`Alt+Shift+Enter`) там появляется число. Если отметить папку **пробелом**, её размер считается
в фоне сам, появляется в колонке «Размер», а внизу в «Отмечено: N · …» папки складываются
с файлами (пока считается — `+ …`). У файлов «Тип» — расширение заглавными (`EXE`, `TXT`),
«Размер» — размер по правому краю.

## Вкладки

Вкладки нарисованы сами: все вкладки белые, активная дополнительно подчёркнута синей полосой;
у каждой «×» и, если вкладка заблокирована, замок. Средняя кнопка мыши закрывает вкладку, правая
открывает меню: копия вкладки, копия на другой панели, переименование, блокировка/разблокировка,
закрыть, закрыть все.

## Панель дисков

Кнопки дисков рисуются сами: значок тома (жёсткий диск, CD/DVD, сетевой диск) и буква. Справа в той же
строке — свободное место и метка тома, как в TC: `C: D: E:   1,2 Тб свободно из 3,6 Тб · Рабочий`.
Для сетевого пути (\\сервер\ресурс) объём показывается с пометкой `сеть`.

## Кнопки

Тулбар, кнопки дисков и ряд F-клавиш рисуются вручную (плоский вид TC-style).

В тулбаре только то, чего нет на F-клавишах: `Обновить`, `Назад`, `Вперёд`, `Вверх`, `Просмотр`, `Поиск`,
`Дерево`, `Очередь`, `Свойства`. Копирование, перенос, создание каталога и удаление оставлены на `F5`–`F8`,
чтобы не дублировать ряд снизу.

Кнопки тулбара — только значки, без подписей. Значки берутся из системного шрифта значков
(`Segoe Fluent Icons`, запасной — `Segoe MDL2 Assets`), поэтому ровные и «родные» для Windows; если шрифта
нет, рисуются встроенные векторные. Подпись появляется подсказкой при наведении.

Подписи F-клавиш меняются при зажатом `Shift`, `Ctrl` и `Alt` — например `Shift+F4 Новый`,
`Ctrl+F5 Размер`, `Alt+F5 Упаковать`.

## Сеть

- Папки по UNC-пути (`\\сервер\ресурс`) открываются как обычные каталоги — через диалог пути, командную
  строку (`cd \\сервер\ресурс`), меню `Сеть → Перейти по UNC-пути…` или запуск с таким рабочим каталогом.
- `Сеть → Обзор сети…` — системный выбор папки с сетевым окружением; выбранный ресурс открывается в панели.
- `Сеть → Подключить сетевой диск…` — `WNetAddConnection2`: UNC-путь и буква диска; диск сразу появляется
  в панели дисков со значком сети.
- `Сеть → Отключить сетевой диск…` — `WNetCancelConnection2` по букве; если панель стояла на этом диске,
  она уходит в каталог программы.

## FTP

- `Сеть → FTP: подключиться…` — профиль (можно выбрать сохранённый или ввести своё имя), адрес, порт,
  логин, пароль, пассивный режим, «Анонимно» и «Сохранить профиль».
  В поле «Сервер» можно вставить как чистый адрес (`194.37.254.233`), так и готовую строку
  `ftp://user@host[:port]/путь` — диалог разберёт её сам. `ftps://` отклоняется с сообщением,
  что TLS не поддерживается.
- Панель открывает `ftp://user@host[:port]/путь`: навигация, маска, сортировка, вкладки и история работают
  так же, как для обычных каталогов. Адрес можно ввести в поле пути или командой `cd ftp://...`.
- Обмен: `F5`/`F6` в любую сторону (локально ↔ FTP, FTP ↔ FTP через временный файл), каталоги — рекурсивно,
  с окном прогресса и «Отменой». `F7` создаёт каталог, `F2` переименовывает, `F8` удаляет **без корзины**,
  `F3` скачивает во временный каталог и показывает файл.
- Если в каталоге назначения уже есть файлы, вопрос задаётся **один раз**: «Да — перезаписать все»,
  «Нет — пропустить существующие», «Отмена». Окно прогресса показывает текущий файл, каталог
  назначения, размер/процент и сколько файлов уже готово.
- Пароль в URL не пишется. Если профиль не сохранён, после перезапуска FTP-вкладка не откроется: пароля уже нет.
- Скорость: для PASV берётся адрес управляющего соединения, а не внутренний IP из ответа
  сервера (иначе каждая операция ждала бы таймаут). Иконки FTP рисуются по расширению,
  без обращений к оболочке; список каталога на реальном сервере — десятки миллисекунд.
- Не поддерживается: FTPS/TLS, SFTP, докачка, правка файлов (`F4`), фоновая очередь, drag&drop,
  архивы/поиск/синхронизация/размер каталога по FTP.
- Проверка: `tools/ftp_test_server.py` (локальный UTF-8 сервер; `--mlsd` включает MLSD) и
  `--ftp-test 127.0.0.1:2121:test:test` (23 проверки, включая кириллицу и рекурсивный размер).

## Иконки

Собственный набор в стиле Total Commander, рисуется в коде:

- папка — классическая жёлтая с язычком, файл — белая страница с загнутым уголком;
- строка `..` — чёрная стрелка вверх;
- у `.exe`, `.lnk`, `.ico`, `.msi` значок берётся из самого файла (у ярлыка — со стрелкой);
- у узнаваемых системных папок (Desktop, Documents, Pictures, Downloads, OneDrive) — значок оболочки;
- скрытые и системные помечаются красной полосой на иконке.

## Перетаскивание

Файлы можно тянуть мышью между панелями, **из Проводника** в панель и **из панели наружу** —
на рабочий стол или в окно Проводника (OLE/CF_HDROP). По умолчанию копирование, с зажатым
`Shift` — перемещение. Бросок в панель, открытую внутри архива или на FTP, отклоняется.

## Что не поддерживается

- **Плагины Total Commander** (`wcx`/`wlx`/`wdx`/`wfx`) — решение и причины в `план.txt`, веха 9.
  Реестр плагинов и диагностика (`--wcx-test`) остались в коде, но архивы через плагины не читаются.
- Правка файлов внутри архива и по FTP, поиск по содержимому архивов, FTPS/SFTP.

## Версия

Версия задаётся в одном месте — `CMakeLists.txt`, строка `project(PosFiles VERSION 1.0.0)`.
Номер сборки — количество коммитов git на момент сборки (без git — 0).

Полная версия вида `1.0.0.112` попадает:

- в свойства exe (VERSIONINFO: компания, описание, версия, сайт и почта — видны в Проводнике);
- в «Помощь → О программе» — вместе с разработчиком и контактами;
- мелкой серой подписью в правом верхнем углу главного окна (в ряду тулбара).

Выпуск новой версии: поменять число в `CMakeLists.txt` и собрать — номер сборки
подставится автоматически.

## Архивы

Zip/7z/rar/tar/gz открываются как папки (`Enter` на файле), распаковка — `F5`, упаковка — `Alt+F5`.
Нужен установленный 7-Zip (`7z.exe`), иначе архивы недоступны, остальное работает.

**ZIP работает и без 7-Zip.** В программу встроен свой движок: чтение оглавления (включая
zip64), распаковка с проверкой CRC и создание архива. На машине без 7-Zip можно открывать,
просматривать, распаковывать и упаковывать zip; остальные форматы (7z, rar, tar, gz, iso)
и пароли требуют 7-Zip.

`7z.exe` ищется в таком порядке: рядом с `PosFiles.exe` (переносной комплект — можно просто
положить файл в одну папку), `Program Files`, реестр установщика 7-Zip, `PATH`. Если архив не
открывается — «Помощь → Проверить 7-Zip…» покажет найденный путь или предложит скачать
7-Zip; путь также виден в «О программе» и в логе `POSFILES_DEBUG`.

Переменная `POSFILES_NO_7Z=1` отключает поиск 7-Zip — так можно проверить встроенный движок
(и работать там, где 7-Zip ставить нельзя).

Встроенный движок без 7-Zip умеет: список, распаковка (файл или каталог), создание архива,
**добавление файлов и каталогов и удаление записей** (каталог — с содержимым). Новые записи
сжимаются своим дефлятором (файлы больше 64 МБ пишутся как есть), а уже сжатые записи при
правке копируются байт в байт. Ограничения: только zip; правка архивов больше 4 ГБ и с числом
записей больше 65535 требует 7-Zip; пароли не поддерживаются.

Поиск (`Alt+F7`) с галочкой «Искать в архивах» находит файлы по имени внутри архивов —
для каждой найденной строки `Enter` сразу открывает архив на нужном каталоге и ставит курсор
на файл (работает и для файла в корне архива, и для вложенного).

Архив можно менять прямо из панелей:

- `F5` копирует выделенное (или файл под курсором) из другой панели **в архив** — в его текущий
  каталог, с сохранением структуры папок; существующие записи с теми же именами заменяются;
- `F6` — то же с последующим удалением исходников (в корзину);
- `F8` в панели, открытой внутри архива, удаляет записи из архива (каталог — со всем содержимым)
  после вопроса; без корзины — восстановить нельзя;
- долгие операции показывают окно с «Отменой».

Ограничения: изменяются только zip, 7z и tar (rar, iso, cab, gz — только чтение); при добавлении
внутрь подкаталога архив переписывается дважды (7z сначала пишет в корень, потом переносит записи),
поэтому на гигабайтных архивах это заметно по времени.

## Структура

```
src/main.cpp      окно, меню, тулбар, командная строка, горячие клавиши
src/panel.cpp     панель: диски, вкладки, виртуальный ListView, сортировка
src/util.cpp      файловая система, форматирование, иконки, лог
src/dialogs.cpp   ввод строки, просмотрщик
src/ops.cpp       копирование/перемещение/удаление/создание каталога
src/ftp.cpp       FTP-клиент: сокеты, UTF-8, MLSD/LIST, RETR/STOR, файловые команды
src/settings.cpp  INI-настройки
src/selftest.cpp  режим --selftest
```
