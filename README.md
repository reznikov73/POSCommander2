# POSCommander 2

Двухпанельный файловый менеджер в духе Total Commander. Чистый Win32 API, C++20, без внешних зависимостей.

Цель — скорость и сходство с TC: запуск до окна ~60–120 мс, память ~15 МБ, exe меньше 1 МБ.

## Сборка

Нужны CMake 3.20+, Ninja и компилятор.

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=g++ -DCMAKE_RC_COMPILER=windres
cmake --build build
```

Готовый файл: `build\POSCommander2.exe`. Проверено на MinGW-w64 GCC 16.1 (`C:\Tools\w64devkit`); MSVC поддерживается в CMake, но на этой машине не проверялся (пресет `msvc-release`).

## Запуск и проверка

```powershell
.\build\POSCommander2.exe              # обычный запуск
.\build\POSCommander2.exe --selftest   # самопроверка, код возврата = число провалов
```

Отчёт самопроверки: `%TEMP%\posc2-selftest.txt`. Диагностический лог: `%TEMP%\posc2-debug.log`.

## Настройки

Файл `POSCommander2.ini` рядом с exe (создаётся при выходе): положение и размер окна, развёрнутость, пропорция разделителя, скрытые файлы, сортировка, пути и вкладки обеих панелей.

Удалить файл — вернуться к значениям по умолчанию.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Tab` | переключить панель |
| `Ctrl+Tab` | следующая вкладка |
| `Ctrl+T` / `Ctrl+W` | новая вкладка / закрыть |
| `Enter` | войти в каталог, открыть файл |
| `Backspace` | наверх |
| `Ctrl+H` | скрытые файлы |
| `Ctrl+A` | выделить всё |
| `Insert`, `Space` | отметить файл |
| `F2` / `Shift+F6` | переименовать |
| `F3` | просмотр (ESC закрывает) |
| `F4` | правка во внешнем редакторе |
| `F5` / `F6` | копировать / переместить |
| `F7` | создать каталог |
| `F8`, `Delete` | удалить в корзину |
| `Alt+Enter` | свойства |
| `Alt+F1` / `Alt+F2` | меню дисков |
| `Ctrl+R` | обновить |

## Структура

```
src/main.cpp      окно, меню, тулбар, командная строка, горячие клавиши
src/panel.cpp     панель: диски, вкладки, виртуальный ListView, сортировка
src/util.cpp      файловая система, форматирование, иконки, лог
src/dialogs.cpp   ввод строки, просмотрщик
src/ops.cpp       копирование/перемещение/удаление/создание каталога
src/settings.cpp  INI-настройки
src/selftest.cpp  режим --selftest
```

Подробный план работ — `план.txt`, история проектирования — `docs/session-history/`.
